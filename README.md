# Paint My Story 💅

The personal portfolio of **Ridhima Motewar**, styled as a luxury futuristic nail art studio.
Live at **https://ridhimamotewar.github.io**

## Features
- 3D vanity table with glossy nail polish bottles as navigation
- Cap-opening + brush paint-stroke transitions between sections
- Scratch-to-reveal nails hiding facts and previews
- Nail art gallery of projects with case-study modals
- "Ask the Nail Artist AI" — a built-in concierge chatbot
- Fully responsive, reduced-motion friendly, zero frameworks

## Editing content
All personal content (projects, case studies, chatbot answers) lives in the
`SITE_CONTENT` object at the top of [script.js](script.js). Section copy
(About, Leadership, Creativity) is plain HTML in [index.html](index.html).

## Running locally
Any static server works, e.g.:

```
npx http-server -p 8317
```

Built with plain HTML, CSS, and JavaScript — no build step required.
